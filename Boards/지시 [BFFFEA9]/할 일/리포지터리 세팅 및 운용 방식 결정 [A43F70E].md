## 작업 내용

개발팀장 강주영과 개발팀 멘토 이강민이 함께 맡는다. GitHub에 프로젝트 저장소를 만들고 TF장 정상원(GitHub 계정 CodeHotel)을 초대한 뒤, 보드의 작업지시서, GitHub 저장소, GitHub Issues, 브랜치가 서로 어떻게 맞물리는지를 두 사람이 논의하여 합의하고, 그 결과를 짧은 계획 문서로 적어 보고 보드에 올린다. 재현 절차와 로그와 코드 수정 논의는 GitHub Issues에, 일정과 시연에 영향을 주는 사항은 Mattermost의 리스크 및 이슈 등록부에 남긴다는 기존 원칙은 유지하되, 작업지시서 카드와 Issue와 브랜치를 어떻게 잇는지, 누가 어느 시점에 검토하고 병합하는지는 두 사람이 정한다. 합의하지 못한 사항은 카드의 결정 필요 사항에 적어 올린다.

## 완료 기준

- 합의하지 못한 사항은 결정 필요 사항으로 적는다.
