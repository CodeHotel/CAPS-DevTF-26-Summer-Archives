## IAM 구성

다른 사용자가 루트 계정 없이 AWS Console에 접속해서 작업할 수 있도록 caps-gpu-develop-users IAM 사용자 그룹을 생성했습니다.

개인 신용카드가 등록되어 있기 때문에 발생한 비용과 예상 비용은 확인할 수 있어야 하지만, 개인 정보 보호를 위해서 결제 수단 정보의 조회 및 변경은 제한할 필요가 있었습니다. 또한 AWS 리소스는 비교적 자유롭게 생성하고 수정할 수 있도록 PowerUserAccess를 부여했지만, 해당 권한에는 IAM 관리 권한이 포함되어 있지 않습니다. 개발 과정에서는 서비스 연동이나 배포를 위해 IAM 사용자 또는 역할을 생성하고 설정해야 하는 경우가 있으므로 제한적인 IAM 관리 권한도 추가로 필요했습니다. 다만 AdministratorAccess와 같이 계정 전체에 대한 관리 권한을 부여하거나, IAMFullAccess를 통해 AdministratorAccess와 같은 최상위 정책을 임의로 부여할 수 있도록 하는 것은 최소 권한 원칙에 적합하지 않다고 판단했습니다.

따라서 하단과 같이 권한 범위와 보안 제약을 설정하고 이를 기반으로 정책을 생성했습니다.

**권한 범위**

- VPC, EC2, 서브넷 등 리소스 편집 권한 부여
- 결제 예상 금액 조회 허용
- 결제 수단(신용카드 정보) 조회, 추가, 변경 금지
- 개발 과정에 필요한 IAM Role 편집 권한 부여
- IAM User/Role 편집은 원칙적으로 차단하되, 개발에 필요한 IAM User/Role만 생성 및 삭제 허용

**보안 제약**

- AdministratorAccess, IAM 전체 편집 권한 등 민감한 정책의 부여 및 수정 금지
- 본인이 속한 IAM 사용자 그룹 편집 금지

| 항목                   | 이름                     | 역할                                                       |
| ---------------------- | ------------------------ | ---------------------------------------------------------- |
| 사용자 그룹            | caps-gpu-develop-users   | 개발자 계정이 속하는 그룹                                  |
| 그룹 정책 (AWS 관리형) | PowerUserAccess          | IAM, Organizations, Account를 제외한 전체 서비스 권한 부여 |
| 그룹 정책 (직접 생성)  | CapsGpuDevelopGuardrails | 제한된 IAM 작업 허용, 민감한 작업 명시적 거부              |
| 권한 경계 (직접 생성)  | CapsGpuWorkloadBoundary  | 개발자가 만든 Role과 User의 권한 상한                      |

## 생성 규칙

이름 규칙와 권한 경계 중 하나라도 빠지면 생성 요청을 거부하도록 설정했습니다.

| 대상                    | 이름 규칙                           | 권한 경계                    | 비고                                   |
| ----------------------- | ----------------------------------- | ---------------------------- | -------------------------------------- |
| IAM Role                | caps-gpu-dev-                       | CapsGpuWorkloadBoundary 필수 | 콘솔의 Role 자동 생성 기능은 사용 불가 |
| 정책, 인스턴스 프로파일 | caps-gpu-dev-                       | 해당 없음                    | 다른 이름의 정책은 수정 불가           |
| 서비스용 IAM User       | caps-gpu-svc-                       | CapsGpuWorkloadBoundary 필수 | 콘솔 로그인 불가, 그룹 소속 불가       |
| 개발자 계정             | 제한 없음 (caps-gpu-svc- 사용 금지) | 해당 없음                    | 관리자만 생성                          |

권한 경계가 붙은 Role과 User는 IAM, Organizations, Account, 결제, 세금, Identity Center 권한을 가질 수 없고, caps-gpu-dev- Role을 서비스에 전달하는 것과 서비스 연결 역할 생성 작업을 수행할 수 있습니다.
