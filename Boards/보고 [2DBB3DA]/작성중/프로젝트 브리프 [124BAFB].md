## 개요

연구실마다 따로 산 GPU를 하나로 묶어, 학생과 연구자가 그래픽카드 일부를 빌려 쓰는 교내 공유 플랫폼.

## 배경

- 문제: 연구실 GPU가 밤과 주말에 놀고, 장비 없는 연구실은 실험을 미룬다
- 계기: 정준호 교수님 의뢰. 다른 연구실을 설득하고 교무회의에서 보일 시연이 필요하다
- 이번 TF의 성격: 시연 가능한 MVP를 만들면서 기획·개발·PM·디자인·QA가 각자 산출물을 남긴다

## 사용자

| 사용자 | 용도 |
|---|---|
| 실습 수강생 | 티어를 골라 인스턴스를 받고 과제를 돌린다. 마흔 명이 동시에 |
| 연구자 | 큰 티어로 하루 종일 세션을 유지하며 실험한다 |
| 관리자 | 노드 등록, 티어 설정, 사용량 확인 |

## 완료 기준

| 산출물 | 완료 기준 |
|---|---|
| MVP | 서버 한 대에서 인스턴스 생성 → SSH 접속 → 상한 안에서 학습 → 종료·회수가 돈다 |
| 시연 영상 | 위 흐름이 화면으로 보이고 교수님이 설명할 수 있다 |
| 검토 보고서 | 구현 방식 선택 근거와 기술검증 결과가 문서로 남아 있다 |

## 범위

- 그래픽카드 한 장을 여러 몫으로 나눠 VRAM 상한을 강제한다 (HAMi)
- 티어별 인스턴스 생성, SSH 접속, 종료
- 홈 볼륨이 세션을 넘어 남는다
- 관리자가 노드 상태를 본다

## 범위 제외

- 노드 여러 대. 한 대에서 시연한다
- 크레딧 회계. 단위와 배분은 장비 조사 뒤 정한다
- 예측 기반 스케줄링. 별도 연구로 분리했다
- 그래픽카드 두 장 이상에 걸친 작업. 장비가 없어 검증하지 못했다

## 전제 조건

| 서버 | 베타 서버 한 대 |
|---|---|
| GPU | RTX 4080 SUPER 16 GB 한 장 |
| 망 | 교내망. 외부 접속은 릴레이 경유 |
