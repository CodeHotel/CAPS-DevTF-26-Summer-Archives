## 11. 교수님 설득을 위한 핵심 질문

이 구간은 마지막에 묻는다. 답변은 가능하면 문장 그대로 기록한다.

### 11.1 API형 실행만 있을 때의 한계

| 질문 | 답변 |
| --- | --- |
| 모든 GPU 사용을 정해진 API형 작업 제출로만 받는다면, 연구실에서 빠질 수밖에 없는 작업은 무엇인가요? |  |
| 그런 작업이 빠지면 연구실 입장에서 이 시스템을 쓰기 어려운 이유는 무엇인가요? |  |
| API형 실행이 가능하려면 최소한 어떤 조건이 갖춰져야 하나요? |  |
| API형 실행이 오히려 편할 것 같은 작업은 무엇인가요? |  |

### 11.2 작업공간 제공 방식만 있을 때의 한계

| 질문 | 답변 |
| --- | --- |
| GPU 작업공간만 빌려주는 방식이면 현재 방식과 크게 다르지 않다고 느낄까요? |  |
| 작업공간만 제공하면 사용 시간 예측, 취소, 실패, 재시도 기록을 충분히 관리할 수 있을까요? |  |
| 사용자가 직접 서버를 만지는 방식에서 가장 관리하기 어려운 점은 무엇인가요? |  |
| 작업공간 제공 방식만으로는 교수님이나 관리자 입장에서 무엇이 부족할까요? |  |

### 11.3 두 방식이 함께 필요하다는 근거

| 질문 | 답변 |
| --- | --- |

| 작업공간에서 반복되던 작업을 나중에 API형으로 옮길 수 있을까요? |  |
| 교수님 회의에서 이 시스템을 설명한다면 어떤 사례를 보여주는 게 가장 설득력 있을까요? |  |
| 이 시스템이 실제로 있다면 연구실에서 써볼 의향이 있나요? 어떤 조건에서 가능한가요? |  |
